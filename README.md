# Prathibha D — Developer Portfolio

A fully responsive, highly animated personal portfolio built with React 19, Vite, and Framer Motion. 

## ✨ Features
- **ML-Themed Preloader:** A custom terminal-style loading sequence simulating a machine learning training loop.
- **Cinematic Animations:** Scroll-triggered reveals, staggered text, 3D card tilts, and magnetic buttons powered by Framer Motion.
- **Accessible by Design:** 0 Axe-core violations, native focus trapping for modals, and full `prefers-reduced-motion` support.
- **Interactive UI:** Filterable project grid, native `<dialog>` modals with deep-linking via hash routing, and responsive mobile navigation.

## 🛠️ Tech Stack
- **Framework:** React 19 + Vite 7
- **Animation:** Framer Motion
- **Styling:** Vanilla CSS (Design tokens, Flexbox/Grid, Media Queries)
- **Testing:** Playwright + Axe-core (Accessibility)

## 🚀 Running Locally
1. Clone the repo: `git clone https://github.com/Prathibha856/prathibha-portfolio.git`
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev`
4. Open `http://localhost:5173` in your browser.
